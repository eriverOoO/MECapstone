# 여유 있는 검사영역 적용 후 재검사

같은 원본 13장과 변형 156장, 총 169장을 다시 처리했습니다. 입력 이미지의 배경·회전·해상도는 바꾸지 않았고 칩 검출 알고리즘도 동일합니다.

인터넷 사진은 구도와 카드 크기가 서로 달라, 원본별로 넉넉한 검색창을 먼저 설정하고 키트에 기록된 이동·회전 정보로 변형 이미지의 검색창을 환산했습니다. 각 검색창의 가로·세로 10%를 매 방향 추가 여백으로 사용했습니다. 칩 위치를 수동으로 지정하지 않았고 카드 경계도 프로그램이 검출합니다. 실제 고정 카메라에서 하나의 ROI를 쓰는 시험과는 다릅니다.

| 표시/판정 | 이전 | 이번 |
|---|---:|---:|
| 카드 검출 표시 | 119 | 107 |
| 칩 검출 표시 | 64 | 64 |
| UNKNOWN | 111 | 123 |
| 칩 없는 뒷면의 칩 검출 표시 | 19 | 19 |
| 읽기/처리 오류 | 0 | 0 |

표시 건수는 정확도가 아닙니다. 판정이 바뀐 12장은 모두 `plain_back`의 변형입니다. 이전에는 카드가 포함된 **사진 자체의 사각형 경계**를 카드로 잡았습니다. 검색창이 그 사진 경계를 제외하자 카드 검출 표시가 사라지고 UNKNOWN이 되었습니다. 실제 작은 카드 자체의 검출은 아직 실패하므로 이를 12건의 올바른 카드 검출로 개선했다고 해석할 수 없습니다.

홀로그램과 비접촉 결제 아이콘의 칩 오검출은 유지되었습니다. **이번에 반영한 것은 카드 검색영역의 여유이며, 칩 예상 위치/접점 형태를 검증하는 추가 필터를 적용한 결과가 아닙니다.**
